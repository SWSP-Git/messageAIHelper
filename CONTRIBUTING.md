# 贡献指南 (Contributing Guide)

感谢您对 `messageAIHelper` 的关注！我们欢迎任何形式的贡献，无论是提交 Bug、提出新功能建议，还是直接提交代码。
Thank you for your interest in `messageAIHelper`! We welcome any form of contribution, whether reporting a bug, suggesting a new feature, or submitting code.

## 🐛 报告 Bug / Reporting Bugs
在提交 Bug 之前，请先搜索 [Issues](issues) 列表，确认该问题是否已被报告。如果没有，请新建一个 Issue，并尽量详细地描述：
Before submitting a bug, please search the [Issues](issues) list to confirm if it has already been reported. If not, please create a new Issue and describe in detail:
- 您的手机型号与 Android 版本 / Your phone model and Android version
- 您使用的 App 版本（如 v1.0.0） / App version (e.g., v1.0.0)
- 复现该问题的具体步骤 / Steps to reproduce the issue
- 预期的行为与实际的行为 / Expected behavior and actual behavior

## 💡 提出功能建议 / Feature Requests
我们非常欢迎新想法！请新建一个 Issue，并详细描述您希望增加的功能及其使用场景。
We welcome new ideas! Please create a new Issue and describe in detail the feature you would like to add and its use cases.

## 💻 代码贡献流程 / Code Contribution Process
我们采用标准的 GitHub Flow 协作流程 / We use the standard GitHub Flow:
1. **Fork** 本仓库到您的账号下 / Fork this repository to your account.
2. 从 `master` 分支创建一个新的功能分支 / Create a new feature branch from `master`.
3. 在您的分支上进行修改，并确保代码可以正常编译 / Make changes and ensure the code compiles.
4. 提交您的修改，并撰写清晰的 Commit Message / Commit your changes with clear messages.
5. 将您的分支推送到您的 GitHub 仓库 / Push to your GitHub repository.
6. 向本仓库的 `master` 分支发起 **Pull Request (PR)** / Submit a Pull Request (PR) to the `master` branch.
7. 等待维护者 Review，并根据反馈进行修改 / Wait for review and make changes based on feedback.

## 🛠️ 开发环境 / Development Environment
- Android Studio (最新稳定版 / Latest Stable)
- Kotlin 1.9+
- Gradle 8.0+
- Android SDK API 26 (Android 8.0) 及以上 / and above

## 📜 代码规范 / Code Style
- 请遵循 Kotlin 官方代码风格 / Follow Kotlin official code style.
- 保持代码简洁，添加必要的注释 / Keep code clean and add necessary comments.
- 提交前请确保没有明显的编译警告或错误 / Ensure no significant warnings or errors before committing.

再次感谢您的贡献！/ Thanks again for your contribution!
